Dynamic Image Slider

A responsive and dynamic image slider built using HTML, CSS, and JavaScript that allows users to smoothly navigate through multiple images with interactive controls. This project focuses on creating a modern, user-friendly slider with automatic transitions and manual navigation features.

Features

• Automatic image sliding (Auto-play)
• Previous and Next navigation buttons
• Smooth transition animations
• Responsive design for mobile and desktop
• Dynamic image loading
• Navigation dots / indicators
• Pause on hover functionality (optional)
• Lightweight and fast performance
